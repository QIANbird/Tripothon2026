# Debugging Protocol

1. Do not scan the whole repository.
2. Start from:
   - exact error
   - reproduction steps
   - recent git diff
3. Identify the owner of the failing behavior.
4. Search for existing working reference implementations.
5. Form 1–3 hypotheses before editing.
6. Prefer the smallest patch.
7. Verify against reproduction steps.
8. Do not refactor unrelated systems.
